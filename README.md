# OfficeReviewBot

Небольшой Telegram-бот для сбора отзывов по номеру заявки (Node.js + [grammY](https://grammy.dev)).

## Как работает

1. Клиент пишет боту `/start` и видит меню с кнопками «📝 Оставить отзыв» и «ℹ️ Помощь».
2. После «Оставить отзыв» бот просит 8-значный номер заявки (ровно 8 цифр; при ошибке объясняет, что не так, и просит ввести снова).
3. Затем бот просит текст отзыва.
4. Отзыв уходит в чат отзывов в виде «📋 Заявка: 12345678» и «💬 @username: текст отзыва» (если username нет — имя со ссылкой на профиль).
5. Клиент получает «Спасибо за ваш отзыв! Рассмотрим в ближайшее время 🙏» и возвращается в меню.

На любом шаге можно отменить кнопкой «❌ Отмена» или командой `/cancel`.

Состояние диалога хранится в памяти: после перезапуска бота незавершённые диалоги сбрасываются.

## Запуск

Нужен Node.js 20.6+.

```bash
npm install
cp .env.example .env
# впишите в .env BOT_TOKEN и REVIEWS_CHAT_ID
npm start
```

Для разработки с автоперезапуском: `npm run dev`.

## Настройка чата для отзывов

1. Добавьте бота в группу (или канал — тогда сделайте его администратором с правом публикации).
2. Узнайте ID чата, например переслав сообщение из него боту [@userinfobot](https://t.me/userinfobot) или через `https://api.telegram.org/bot<TOKEN>/getUpdates` после сообщения в группе. ID групп обычно имеет вид `-100…`.
3. Укажите его в `REVIEWS_CHAT_ID`.
